# Feature Specification: 拆螺丝益智游戏 (Unscrew Puzzle)

**Feature Branch**: `004-unscrew-puzzle`  
**Created**: 2026-01-26  
**Status**: Draft  
**Input**: User description: "新增拆螺丝游戏"

## 用户场景与测试 (User Scenarios & Testing)

### User Story 1 - 基础拆卸与掉落机制 (Priority: P1)

用户进入游戏后，可以看到由若干螺丝固定在背景板上的金属板（或其它形状物体）。用户点击一个螺丝，螺丝会从当前位置拔出并移动移动到上方的备用槽位中。若某块金属板失去所有支撑它的螺丝，受重力影响掉落出屏幕。

**Why this priority**: 这是游戏的核心玩法，只有实现了螺丝的拆卸和物体的物理掉落，游戏才具备基本的娱乐价值。

**Independent Test**: 用户可以通过点击螺丝将其移入槽位，并观察到金属板在失去支撑后掉落，成功清除所有金属板即为测试通过。

**Acceptance Scenarios**:

1. **Given** 关卡中有被两个螺丝固定的长条形板，**When** 用户依次点击这两个螺丝，**Then** 两个螺丝依次进入上方空槽位，长条形板掉落。
2. **Given** 关卡中有相互重叠的板，**When** 下层的板被拆除，**Then** 上层的板位置保持不变（由其自身螺丝固定）。

---

### User Story 2 - 限位槽管理与失败判定 (Priority: P2)

用户需要管理屏幕上方的螺丝存放槽位。如果所有的存放槽位都被占满，且场景中没有可以由于螺丝移除而产生的空位，玩家将无法继续操作。

**Why this priority**: 引入了策略性，玩家必须考虑拆卸螺丝的顺序，避免槽位被锁死，这是提高游戏耐玩性的关键。

**Independent Test**: 填满所有上方槽位，验证此时点击场景中的螺丝无法被移除，并显示失败提示。

**Acceptance Scenarios**:

1. **Given** 上方有3个空槽位且已存放3个螺丝，**When** 用户尝试点击场景中的第4个螺丝，**Then** 螺丝发出抖动提示但无法移动，玩家无法继续。
2. **Given** 一个螺丝槽位被清空（例如通过道具或关卡机制），**When** 用户再次点击场景中的螺丝，**Then** 螺丝可以被成功移动。

---

### User Story 3 - 关卡进度与胜利奖励 (Priority: P3)

用户在清除屏幕上所有的金属板后，游戏判定胜利，显示得分并进入下一关。

**Why this priority**: 完整的闭环体验，让用户有成就感和持续游戏的动力。

**Independent Test**: 清除最后一个遮挡物，验证结算界面正确弹出并能跳转到下一关。

**Acceptance Scenarios**:

1. **Given** 场景中仅剩最后一块金属板，**When** 用户移除最后一个固定螺丝使板掉落，**Then** 屏幕显示“胜利”字样及本关得分。

---

### Edge Cases

- **重叠孔位**: 当两块板共用一个螺丝孔时，移除螺丝应同时释放两块板在该点上的约束。
- **碰撞体交互**: 掉落的板在下落过程中应与场景中的其它螺丝或尚未掉落的板产生物理碰撞，可能导致卡住的情况。
- **撤销与复活**: 用户可以撤销上一步操作。当所有槽位占满且无法继续时，用户可以通过特定机制（如消耗体力或观看激励视频）清空部分槽位或增加临时槽位以获取复活机会。

## 功能与数据需求 (Requirements)

### Functional Requirements

- **FR-001**: 系统必须提供一个 2D 物理环境，模拟重力对金属板的影响。
- **FR-002**: 系统必须支持点击交互，识别用户选中的螺丝对象。
- **FR-003**: 系统必须维护一个“空孔位/槽位”列表，用于存放从板上拆下的螺丝。
- **FR-004**: 当一个螺丝被移除时，系统必须更新受其约束的所有板实体的物理状态。
- **FR-005**: 掉落的板离开屏幕底部一定距离后，系统必须将其销毁以节省资源。
- **FR-006**: 系统必须能够检测关卡胜利状态（所有指定清除目标物均已离开屏幕）。
- **FR-007**: 系统必须支持“撤销”功能，允许玩家回退到前一操作状态。
- **FR-008**: 系统必须支持“失败复活”机制，在槽位占满时允许清理槽位或增加临时槽位。
- **FR-009**: 游戏必须具备关卡重置功能。

### Key Entities _(include if feature involves data)_

- **螺丝 (Screw)**: 代表固定件，具有位置、颜色（可选）以及它所约束的金属板实体列表。
- **金属板 (Plate)**: 代表需要通过拆卸掉落的物体，具有形状、质量和物理碰撞体。
- **孔位 (Hole)**: 代表螺丝可以放置的位置，包括备用槽位和金属板上的孔。

## Assumptions

- 游戏采用 2D 俯视或侧视视角，受重力向下掉落。
- 默认不包含限时挑战，玩家可以慢慢思考顺序。
- 初始版本不包含付费点（如购买额外槽位）。

## 成功标准 (Success Criteria)

### 可衡量指标

- **SC-001**: 用户能在 10 秒内理解如何拆卸螺丝并开始游戏。
- **SC-002**: 物理效果表现顺滑，金属板掉落时帧率稳定在 60 FPS (在标准移动端设备上)。
- **SC-003**: 100% 正确判定胜利和失败逻辑，无死循环或逻辑卡死。
- **SC-004**: 关卡加载时间不超过 2 秒。
